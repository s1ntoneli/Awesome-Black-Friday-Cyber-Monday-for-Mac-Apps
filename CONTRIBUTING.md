# Contributing a Black Friday 2026 Mac App Deal

We welcome pull requests for macOS apps, Mac-compatible tools, and genuinely useful AI apps. Native macOS software is preferred; label browser-only products clearly. This is a **2026 list**, not a place to repost expired coupons.

## Required in every submission

- Official product URL (prefer the maker's site; no link shorteners).
- Concise description, correct category, and platform (native Mac vs. web-based).
- Exact savings and eligibility (plan, one-time/lifetime/annual, new customers only, etc.).
- Coupon code or **No code needed**, plus **2026** start and end dates.
- Disclosure if you are the maker or receive referral/affiliate compensation.

Use the existing six-column table format: **Badge | App | Type | Description | Offer | 2026 dates**. Place your app in the appropriate category. If the app is already listed, edit the existing row rather than introducing a duplicate.

Deal badges: 🔥 50%+, 💎 20–49%, ✨ under 20%. If a deal has no percentage, explain the pricing in the Offer column and use no badge (—).

Maintainers may shorten descriptions, group many listings from one publisher, or decline deals that cannot be checked. Publication does **not** imply independent coupon verification. Expired years belong in the archive.
